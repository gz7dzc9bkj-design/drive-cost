# ドライブ料金（drive-cost）

現在地から目的地までの **高速道路料金 ＋ ガソリン代** を出す個人用アプリ。
サーバー不要の静的PWA。iPhoneのホーム画面に置いて使う。

**公開URL: https://gz7dzc9bkj-design.github.io/drive-cost/**

---

## 使い方（3ステップ）

### 1. 最初に1回だけ準備する

| タブ | やること |
|---|---|
| 設定 | 車を登録する（名前・普通車/軽自動車・燃費）。よく使う車から順に |
| 設定 | ガソリン単価の既定値を入れる |
| 登録 | よく行く場所を登録する（「名前で座標を検索」→ 追加） |
| 登録 | よく使うICを登録する（**「IC名で座標を検索」まで行うと料金の概算が出る**） |

### 2. 高速料金について

**ICに座標を入れておけば、登録しなくても「概算」が自動で出る。**
ただし割引を含めない計算のため、長距離では実額より1〜2割高く出る。

正確な額にしたいときは、［ドラぷらで調べる］→ 金額を確認 →
入力欄に入れて［保存］。**2回目以降はその区間の正確な額が自動で出る。**

表示の優先順位:

| 表示 | 意味 |
|---|---|
| 金額のみ | その車種で登録済み（一番正確） |
| **換算** バッジ | もう一方の車種の登録額から比率0.8で換算 |
| **概算** バッジ | IC間の距離から計算した目安（高めに出る） |
| 未登録 | ICに座標が入っていない。登録タブで「IC名で座標を検索」すると概算が出る |

### 3. 毎回の使い方

車を選ぶ → 出発地（現在地ボタン or 登録地点）→ 目的地 → 入口IC・出口IC → 合計が出る。

**入力した内容は自動で保存される。** アプリを閉じて開き直しても、出発地・目的地・IC・
距離・往復の設定はそのまま復元される（圏外でも前回の数値が残る）。

## 起動方法

### PCで確認する

```bash
node tools/serve.js
```

→ http://localhost:8124

### iPhoneで使う

**https://gz7dzc9bkj-design.github.io/drive-cost/** を Safari で開き、
共有ボタン →「ホーム画面に追加」。
以後はアプリのアイコンから起動でき、圏外でも登録済みの料金で計算できる。

`main` に push すると自動で再公開される。`.nojekyll` は消さないこと
（GitHub Pages の既定の Jekyll 処理でビルドが落ちるため）。

## 開発時のきまり

**コードを変更したら必ず検査を通すこと。**

```bash
node tools/verify.js
```

- `[A]` 全JSの構文
- `[B]` 凍結事項（logic.jsの純粋性・車種2値・相対パス・PRECACHE漏れ など）
- `[C]` ロジックテスト34件

詳しい規約は [CLAUDE.md](./CLAUDE.md)、仕様は [docs/REQUIREMENTS.md](./docs/REQUIREMENTS.md)。

アイコンを作り直す場合: `node tools/make-icons.js`

IC一覧を最新にする場合（新しいICが開通したとき）: `node tools/build-ic-data.js`
→ `data/interchanges.json` を作り直す。1〜2分かかる。**PowerShellで取得しないこと**
（UTF-8が壊れてIC名が全滅する）。

## 既知の制限

- **純正マップの距離の数字は取り込めない**（iOSの仕様。他アプリから経路結果を読めない）。
  距離はOSRMの計算値で、マップと数km差が出る。気になるときは［直す］で手入力する
- **高速料金は ETC・通常料金のみ**。深夜割・休日割などの割引は考慮しない（仕様）
- **普通車と軽自動車のみ**。中型車・大型車には対応しない
- 片方の車種しか登録していない区間は比率0.8で換算した**概算**（バッジが出る）
- IC名の検索は、OpenStreetMap に登録されている名前でしか当たらない
  （例:「川口IC」は存在せず「越後川口IC」が出る）。**座標は空欄のままでも使える**
- OSRM は公開のデモサーバーで無保証。落ちた場合は距離を手入力するか、
  設定から OpenRouteService（無料キー）に切り替える
- データはこの端末のブラウザ内のみ。機種変更時は設定タブの［書き出し］→ 新端末で［読み込み］
