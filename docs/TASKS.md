## R1. logic.js（凍結モジュール）とテスト

- **目的**: 計算の中核を純粋関数で確定させる
- **ファイル**: `js/logic.js`, `tests/logic.test.js`
- **完了条件**: DESIGN.md 第4節の全関数を実装。テスト20件以上が通る
- **テストケース（必須）**
  | 入力 | 期待値 |
  |---|---|
  | `fuelCost(182.4, 15.0, 175)` | `2128`（円未満切り捨て） |
  | `fuelCost(100, 0, 175)` | `null`（ゼロ除算を弾く） |
  | `fuelCost(0, 15, 175)` | `0` |
  | `convertToll(8140,"normal","kei")` | `6510`（8140×0.8=6512 → 10円単位に丸め） |
  | `convertToll(6510,"kei","normal")` | `8140`（6510÷0.8=8137.5 → 10円単位に丸め） |
  | `convertToll(1000,"kei","kei")` | `1000`（同一車種は素通し） |
  | `findToll` 完全一致あり | `{yen:8140, exact:true}` |
  | `findToll` 他車種のみ登録 | `{yen:6510, exact:false}` |
  | `findToll` 該当なし | `null` |
  | `totalCost(2128, 4830, false)` | `6958` |
  | `totalCost(2128, 4830, true)` | `13916`（往復＝両方2倍） |
  | `formatDistanceKm(361925.1)` | `361.9` |
  | `isTollStale("2025-08-14","2026-08-15")` | `true`（1年超） |
  | `isTollStale("2026-08-01","2026-08-15")` | `false` |
  | `tollKey("i1","i2","kei")` | `"i1>i2#kei"` |
