# drive-cost 要件定義書

**凍結: 2026-08-14 ユーザー承認済み**
以後この内容を変更するときは必ずユーザーに確認する。

---

## 1. これは何か

現在地から目的地までのドライブにかかる **高速道路料金 + ガソリン代** を出す、
iPhone のホーム画面から使う個人用の計算アプリ（PWA）。

純正マップの「代わり」ではなく、**マップの隣で使う料金電卓**という位置づけ。

### 利用者・利用シーン
- 利用者: 本人のみ（1人）
- 端末: iPhone（Safari → ホーム画面に追加）。PC のブラウザでも同じものが動く
- 場面: 出発前に「今日はいくらかかるか」を把握する
- 頻度: 1日数回以下

---

## 2. 技術的な前提（重要 / 覆せない制約）

| # | 制約 | 設計への影響 |
|---|---|---|
| ① | 純正マップは日本の高速料金を表示しない | 料金はマップから取れない → 別手段が必要 |
| ② | 他アプリ/ショートカットから純正マップの経路結果（距離・ルート）を読み出せない。できるのはマップを「開く」ことだけ | 距離はアプリ側で経路APIから自前計算する |
| ③ | NEXCO に無料の公式料金APIが存在しない（ドラぷらはWeb検索のみ） | 料金は「1回調べて登録・保存」方式にする |

---

## 3. 決定事項（ユーザー承認済み）

| 項目 | 決定 |
|---|---|
| 高速料金の出し方 | **A方式: 調べて登録・保存**。新しいICの組み合わせだけ初回にドラぷらで調べて入力し、以後は自動適用 |
| 走行距離 | **経路APIで自動計算 + 手動上書き可**。普段は自動、気になるときだけタップして直す |
| 目的地の指定 | **① 登録済み地点から選ぶ ② 地名・住所で検索** の2通り |
| 現在地 | GPS で取得し **出発地に自動入力** |
| **車種** | **普通車 / 軽自動車 を切り替えられる**（料金・燃費とも車種ごと） |
| 高速料金の条件 | **ETC・通常料金（一番高い値段）**。深夜割・休日割・平日朝夕割・長距離逓減などの割引は一切考慮しない |
| 形態 | 静的PWA（GitHub Pages 公開・サーバー不要・登録済みルートはオフラインでも計算可能） |
| データの保存先 | 端末内 localStorage のみ。クラウド同期なし |
| 外部API | **APIキー登録は不要**（下記の通り実測で確認済み） |

### 採用する外部API（2026-08-14 実測で検証済み）

| 用途 | サービス | キー | 検証結果 |
|---|---|---|---|
| 地名・施設名の検索（主） | Nominatim (OpenStreetMap) | **不要** | HTTP 200 / `Access-Control-Allow-Origin: *` / 「東京駅」で東京駅が正しく先頭に返る |
| 住所検索（予備） | 国土地理院 住所検索API | **不要** | HTTP 200 / CORS `*`。**住所専用**で「東京駅」を「東」と解釈するため主には使わない（実測で判明・2026-08-15） |
| 経路距離の計算 | OSRM 公開ルーティングサーバー | **不要** | HTTP 200 / `Access-Control-Allow-Origin: *` / 東京駅→仙台駅 = 361.9km（実距離と整合） |
| 予備の経路API | OpenRouteService | 任意 | OSRM が不調なときのみ、設定画面で無料キーを貼れば切り替わる |

Nominatim は利用規約に沿って **呼び出し間隔を1秒以上あける**実装にしている。

## 4. 入力と出力

### 入力（ユーザーが変更できる項目）
1. **出発地** — 現在地(GPS) / 登録地点から選択 / 地名・住所で検索
2. **目的地** — 登録地点から選択 / 地名・住所で検索
3. **入口IC・出口IC** — 登録済みICから選択（＝「経由するインターチェンジ」の指定）
4. **車両** — 登録した車両プリセットから選択（名前・車種・燃費をまとめて持つ）
5. **燃費** — km/L（車両プリセットの値が入る。画面上で都度変更可）
6. **ガソリン単価** — 円/L（設定に保存。画面上でも都度変更可）
7. **往復トグル** — ON で高速料金・ガソリン代を2倍にする
8. **距離の手動上書き** — 自動計算値をタップして直接入力できる

### 出力
```
走行距離      182.4 km   （自動 / 手動上書き中の表示切替あり）
ガソリン代    2,130 円   （距離 ÷ 燃費 × 単価、**10円単位に切り上げ**）
高速道路料金  4,830 円   （車種別の登録済み料金。未登録なら「未登録」）
─────────────────────
合計          6,960 円
```

---

## 5. 車種の扱い（普通車 / 軽自動車）

- 画面上部で **普通車 ⇔ 軽自動車** を切り替える
- 高速料金は **入口IC・出口IC・車種の3点セット**で登録・保存する
- **片方の車種だけ登録済みの場合**は、NEXCO の車種間料金比率（軽 = 普通車 × 0.8）で
  概算値を表示し、**「概算」バッジを必ず付ける**。正確な値を入れたければ登録すればよい
- ガソリン燃費は車両プリセットが持つ（例: 「アルト（軽）22.0 km/L」「ヴォクシー（普通車）13.5 km/L」）

---

## 6. 高速料金の登録フロー（A方式の実際の動き）

1. 入口IC・出口IC・車種を選ぶ
2. その組み合わせの料金が **登録済みなら即表示**
3. 未登録なら「未登録」と表示し、**［ドラぷらで調べる］ボタン**を出す
4. ボタンでドラぷら（NEXCO 料金検索）を開く → 金額を確認
5. アプリに戻って金額を入力 → **その組み合わせの料金として保存**
6. 以後、同じ組み合わせは自動で出る

料金には「更新日」を持たせ、古い場合（1年以上前）は注意表示を出す。

---

## 7. 保存するデータ

| 種類 | 内容 |
|---|---|
| 設定 | ガソリン単価、選択中の車両、経路APIの切替設定 |
| 車両 | 名前 + 車種(普通車/軽) + 燃費(km/L) |
| 登録地点 | 名前 + 緯度経度（例: 自宅、実家、ゴルフ場） |
| 登録IC | IC名 + 緯度経度（任意。あれば経路の経由地として使う） |
| 料金 | 入口IC・出口IC・車種・金額・更新日 |

---

## 8. スコープ外（やらないこと）

- **各種割引**（深夜割・休日割・平日朝夕割・長距離逓減など）— 通常料金のみ
- **中型車・大型車・特大車・二輪の料金** — 普通車と軽自動車のみ
- **首都高・阪神高速などの自動計算** — 登録制なので個別に登録すれば使える
- **リアルタイム渋滞・所要時間の表示**
- **純正マップからの数値の自動取り込み** — 技術的に不可能
- **IC以外の経由地の指定**（v1では対象外）
- **クラウド同期・複数端末での共有・バックアップ**
- **iOSショートカット単体での実装** — ICとルートのデータ管理が破綻するため採用しない
  （アプリを開く入口としてショートカット/Siri を併用するのは将来的に可）
